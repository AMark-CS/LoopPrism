## Features

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>🗂 Sessions</h4>
      Every Claude Code and Codex session on your machine. Search all messages, group by day or
      project, resume in Terminal, export to Markdown, move to the Trash.
    </td>
    <td width="50%" valign="top">
      <h4>🧭 Trajectory</h4>

    </td>
  </tr>
  <tr>
    <td valign="top">

      injected context, skills, tool results. Window fill, trend, cache hit rate.
    </td>
    <td valign="top">
      <h4>💸 Cost</h4>
      Real token usage priced at the providers' current API prices, split by token type, by what
      filled the context, by model and by turn. See where the money actually goes.
    </td>
  </tr>
  <tr>
    <td valign="top">
      <h4>⏱ Timing</h4>
      Thinking vs answering vs tool time, and tokens per second.
    </td>
    <td valign="top">
      <h4>🔌 MCP tracing &amp; live runs</h4>
      An optional proxy records every MCP tool call; hooks record what an agent does as it happens.
    </td>
  </tr>
  <tr>
    <td colspan="2" valign="top">
      <h4>🤖 Agents</h4>
      A session that spawns subagents gets a flow view: the main agent as a line, each subagent

      are not read yet.)
    </td>
  </tr>
</table>

Everything stays on your machine: SQLite on disk, no Docker, no cloud, no account.

## Get started

### Desktop app (macOS and Windows) — recommended

**macOS**

1. Download the `.dmg` from the [latest release](https://github.com/AMark-CS/LoopPrism/releases/latest)
   (`arm64` for Apple Silicon, `x64` for Intel) and drag **LoopPrism** into Applications.
2. Open it. First launch: right-click the app → **Open** (it is not notarized yet), or
   `xattr -dr com.apple.quarantine /Applications/LoopPrism.app`.

**Windows (x64)**

1. Download `LoopPrism-<version>-x64.exe` from the [Windows preview release](https://github.com/AMark-CS/LoopPrism/releases)
   (the pre-release named "LoopPrism for Windows") and run it (installs for your user only, no administrator prompt).
2. It is not code-signed yet, so SmartScreen may warn: click **More info → Run anyway**.

That's it. The app bundles everything (no Python, no terminal), opens on your sessions, connects
Claude Code and Codex for live runs, and keeps running from the menu bar (macOS) or system tray (Windows). Details:
[desktop/README.md](desktop/README.md).

### Command line

```bash
pip install "git+https://github.com/AMark-CS/LoopPrism.git"   # or: uv tool install git+https://github.com/AMark-CS/LoopPrism.git
lprism proxy                                                    # then open http://localhost:8080
```

### Live runs from Claude Code and Codex

Sessions are read after the fact. To also watch an agent **as it works**:

```bash
npx loopprism install     # adds the hooks to Claude Code and/or Codex, whichever you have
lpa status                # newest runs
```

Claude Code can also use the plugin directly (`/plugin marketplace add AMark-CS/LoopPrism`, then
`/plugin install loopprism@loopprism`). In Codex, run `/hooks` once to trust the hooks. Privacy
options and uninstall: [npm/README.md](npm/README.md).

## How it works

LoopPrism reads the session files Claude Code (`~/.claude/projects`) and Codex (`~/.codex/sessions`)
already write, indexes them locally, and works out the rest.

**How exact is the context breakdown?**

| Source | What's recorded | Result |
|---|---|---|
| Claude Code 2.1.308+ | the exact request of every step (system prompt, tool schemas, messages) | **Exact request**: real content, scaled to the token counts the model reported |
| Codex | system prompt, tool schemas and conversation | **Exact request**, within a few percent |
| Older Claude Code | conversation only | **Estimated**: system prompt and tool schemas inferred as whatever the conversation doesn't explain |

**Cost** is each step's token usage (including cache reads and writes) priced at Anthropic's and
OpenAI's published API prices (`src/loopprism/cost/pricing.py`). It is what the work would cost on
the API; Claude Pro/Max and ChatGPT plans bill differently, and models without a published price
show no cost rather than a guess. Override any price in `~/.loopprism/pricing.json`:

```json
{"claude-opus-5-5": {"input": 4, "output": 20, "cache_read": 0.2, "cache_write": 5, "cache_write_1h": 8}}
```

**Privacy.** Session content (prompts, code, tool output) never leaves your machine. The session
endpoints only answer your own dashboard (loopback host, same origin), so other websites can't
read or delete sessions. Deleting moves a file to the Trash and only works inside Claude Code's and
Codex's own session folders.

## More

<details>
<summary><b>MCP proxy</b> — record MCP tool calls from any HTTP MCP client</summary>

<br>

```bash
lprism proxy --port 4317
```

```jsonc
// e.g. Claude Desktop config
{
  "mcpServers": {
    "github": { "url": "http://localhost:4317/github?backend=https://api.github.com/mcp" },
    "filesystem": { "url": "http://localhost:4317/fs?backend=http://localhost:3001" }
  }
}
```

Every call then appears under **Live runs** with a waterfall of timing and latency, plus per-server
and per-tool stats. The desktop app's **Apps** page builds these URLs for you.

</details>

<details>
<summary><b>Commands</b></summary>

<br>

```bash
lprism proxy                                  # proxy + dashboard
lprism proxy --port 4317 --dashboard-port 8080
lprism proxy --no-dashboard                   # proxy only
lprism dashboard --db ~/.loopprism/remote.db  # dashboard for another database
lprism analyze <trace-id>                     # analyze one trace
lprism proxy --verbose                        # debug logging
```

</details>

<details>
<summary><b>Development</b></summary>

<br>

```bash
git clone git@github.com:AMark-CS/LoopPrism.git && cd LoopPrism
pip install -e ".[dev]" && pytest

cd dashboard && npm install && npm run dev        # dashboard dev server

# try the inspector on made-up sessions (not yours)
python scripts/make_demo_sessions.py /tmp/lp-demo
CLAUDE_CONFIG_DIR=/tmp/lp-demo/.claude CODEX_HOME=/tmp/lp-demo/.codex lprism proxy
```

Build the desktop app (macOS, Windows): [desktop/README.md](desktop/README.md).

</details>

<details>
<summary><b>Renamed from toolglass</b></summary>

<br>

The Python package is `loopprism` and the CLI is `lprism`; the former `toolglass` and `loopprism`
commands no longer exist. `TOOLGLASS_*` environment variables and `X-Toolglass-*` headers still work;
new variables use `LOOPPRISM_*` and take precedence. Existing `~/.toolglass/traces.db` and
`config.toml` are used when their new equivalents are absent; nothing is moved or deleted.
There is no PyPI release yet; install from GitHub.

</details>
